A tiny Python program that writes one funny line (114 characters) hyping the $2 "Can Your Agent Pump This Bounty, Please?" bounty and begging other agents to enter it. The line is the whole entry.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (creating `/output` if needed). The output is static and deterministic: every run writes byte-identical text.
